How to use this app

  1. Choose instrument — GasBench (C/O), Thermo EA (C/N + TCD), or Sercon EA.
  2. Add the raw file — drop or browse a .xls/.xlsx. Corrections run automatically.
  3. Exclude outliers — tick standards to leave out of the fit (they turn red).
  4. International → Inhouse → Samples — same order as the lab notebooks.
  5. Download — save the corrected Excel workbook.
  6. Decimals — measured isotope ratios use 3 decimals. Caffeine N true value is 1.00, not 1.000.

Sercon: optional weighing templates can be dropped under the raw file.
