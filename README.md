# Isotope correction (web)

Statisk shinylive-udgave af workspace-root `app.R` (Thermo GasBench | Thermo EA | Sercon EA).

**Live:** https://joch1993.github.io/Isotope-web-version/

Repo: https://github.com/joch1993/Isotope-web-version

Første indlæsning kan tage et minut (R kører i browseren). Upload af `.xlsx` kan fejle i browseren — brug CSV hvis det sker.

GitHubs web-upload tillader kun 100 filer ad gangen. Hele sitet (~230 filer) er derfor pushet med git; du behøver ikke uploade `shinylive/` manuelt.
